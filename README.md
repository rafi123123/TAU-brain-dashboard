# Missing folders dashboard

service to get all mri scan in the storage server for display in a grafana dashboard

# how to run

## docker

**Start up**
```sh
docker compose up --build -d
```

**Shut Down**
```sh
docker compose down
```

**get logs**

```sh
docker logs dashboard_project-api-1
```

then navigate to http://127.0.0.1:3000 in the browser.
the admin password is `admin`.
Go to `Dashboards` > `missing folders`


## Database queries (sqlc)

The DB access code in `api/db/` (`models.py`, `query.py`) is generated by
[sqlc](https://sqlc.dev) with the [sqlc-gen-python](https://github.com/sqlc-dev/sqlc-gen-python)
plugin as pydantic models + an async SQLAlchemy querier. Don't edit those files by hand: change
`api/db/schema.sql` (tables) or `api/db/query.sql` (queries) and regenerate:

```sh
# one-time install of the sqlc binary
curl -sSL https://downloads.sqlc.dev/sqlc_1.31.1_linux_amd64.tar.gz | tar xz -C ~/.local/bin sqlc

sqlc generate
```

Or without installing anything, via docker:

```sh
docker run --rm -u $(id -u):$(id -g) -e HOME=/tmp -v "$PWD":/src -w /src sqlc/sqlc:1.31.1 generate
```

Use `diff` instead of `generate` to check the generated code is up to date.
`api/sql.py` wraps the generated querier, and runs `schema.sql` on startup to create the tables.

## Tests

```bash
pip install -r requirements-dev.txt
pytest tests/
```

The SMB share and the Google Sheet are always faked. Postgres is real: a temporary `postgres:17`
container is started with docker, or set `TEST_DATABASE_URL` to use an existing **throwaway**
database (tables are dropped before every test).
